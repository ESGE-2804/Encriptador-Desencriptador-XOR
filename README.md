# Encriptador XOR con Clave Aleatoria (Python)

Este programa aplica un método simple de **cifrado y descifrado XOR** sobre un texto ingresado por el usuario, utilizando una **clave aleatoria** de bits (`0` o `1`) generada mediante el módulo `random`.


El cifrado XOR (operación **“exclusive OR”**) consiste en aplicar una operación lógica entre los valores ASCII del texto y los valores de una clave.  

Si se aplica la inversa en la inversa de XOR se logra desencriptar la informacion.
